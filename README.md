# 📋 공모주 청약 캘린더 (자동 갱신)

38커뮤니케이션 공모주 청약 일정을 매일 자동으로 수집해 `.ics` 캘린더로 발행합니다.
애플/구글 캘린더에서 **URL 구독**으로 추가하면 새 공모주가 자동으로 반영됩니다.

## 구독 방법

### 아이폰 / 아이패드 / 맥 (애플 캘린더)
1. **설정 → 캘린더 → 계정 → 계정 추가 → 기타**
2. **구독 캘린더 추가** 선택
3. 아래 URL 붙여넣기:
   ```
   https://raw.githubusercontent.com/tmtmaj/ipo-calendar/main/ipo.ics
   ```
4. **다음 → 저장**

→ iCloud로 모든 애플 기기에 자동 동기화됩니다.

### 구글 캘린더
1. 다른 캘린더 **+ → URL로 추가**
2. 위 URL 붙여넣기

## 일정 종류
- 📋 **[청약]** — 청약 기간 (당일 오전 9시 알림)
- 🔥 **[청약]** — 기관경쟁률 1,000배↑ 따상 후보
- 🔔 **[상장]** — 신규상장일 (시초가 매도 검토)

각 일정 설명란에 기관경쟁률·의무확약·확정공모가·주간사가 표시됩니다.

## 자동 갱신
GitHub Actions가 매일 09:00 / 15:00 (KST) `ipo.ics`를 재생성합니다.

## 로컬 실행
```bash
pip install -r requirements.txt
python generate_ipo_ics.py          # 전체 (상세 정보 포함)
python generate_ipo_ics.py --fast   # 청약 일정만 (빠름)
```
